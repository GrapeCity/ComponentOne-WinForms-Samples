####Interactive Date Range Picker
____
This sample demonstrates a date range picker application built with C1DateRangeEdit. The application provides an interface for selecting date ranges through multiple methods including predefined options.

Key features include:
- Multi-cultural support with localized UI text for English (en-US), Korean (ko-KR), and Japanese (ja-JP)
- Multi-calendar display with custom visual highlighting for selected date ranges
- Predefined date range options
- Configurable date limits (min/max dates) and selection count restrictions
- Culture-specific date formatting and ordinal number display
- Configurable calendar dimension
